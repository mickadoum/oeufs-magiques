# Les Œufs Magiques

Jeu pour apprendre et réviser les tables de multiplication, les additions et les soustractions (niveau CE1).

**Jouer :** https://mickadoum.github.io/oeufs-magiques/

Sur iPad : ouvrir le lien dans Safari, toucher le bouton Partager, puis « Sur l'écran d'accueil ».
Le jeu fonctionne ensuite sans internet. Les progrès restent sur l'appareil.

## Le Cahier Magique

Tout le programme de CE1 dans le même carnet : 29 fiches rangées par matière, plus un défi du jour qui change chaque jour.
Chaque fiche commence par une courte leçon animée, lue à voix haute par l'appareil, puis pose 10 questions.

- Mathématiques : nombres jusqu'à 1 000, fractions, calcul, opérations posées, problèmes, mesures, monnaie, géométrie, solides, tableaux et diagrammes.
- Français : grammaire, conjugaison, orthographe, vocabulaire.
- Questionner le monde, vivre ensemble (enseignement moral et civique), anglais, arts et musique.

Les fiches sont dans `cahier/fiches-maths.js`, `cahier/fiches-francais.js` et `cahier/fiches-monde.js`.

**Ouvrir les fiches :** https://mickadoum.github.io/oeufs-magiques/cahier/

Même installation : ouvrir le lien dans Safari, Partager, puis « Sur l'écran d'accueil ».
C'est une deuxième icône, séparée du jeu, qui fonctionne aussi sans internet.
