# Les Œufs Magiques

Jeu pour apprendre et réviser les tables de multiplication, les additions et les soustractions (niveau CE1).

**Jouer :** https://mickadoum.github.io/oeufs-magiques/

Sur iPad : ouvrir le lien dans Safari, toucher le bouton Partager, puis « Sur l'écran d'accueil ».
Le jeu fonctionne ensuite sans internet. Les progrès restent sur l'appareil.

## Le Cahier Magique

Fiches de révision du programme de CE1, dans le même carnet : les polygones (géométrie), le calcul,
le temps et les unités de mesure, plus un défi du jour qui change chaque jour.

**Ouvrir les fiches :** https://mickadoum.github.io/oeufs-magiques/cahier/

Même installation : ouvrir le lien dans Safari, Partager, puis « Sur l'écran d'accueil ».
C'est une deuxième icône, séparée du jeu, qui fonctionne aussi sans internet.

Programme de référence : cycle 2, BO n° 41 du 31 octobre 2024 (français et mathématiques en vigueur
depuis la rentrée 2025).
